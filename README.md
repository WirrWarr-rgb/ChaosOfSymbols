A highly flexible and modifiable C++ console game featuring procedural world generation, dynamic world evolution, and extensive customization options.

## Overview

Chaos Of Symbols is a top-down console-based game where every character represents a unique object in the world. Built with C++ in Visual Studio Code, the game combines procedural generation with cellular automata to create a dynamic, ever-changing environment.

### Key Features

- **Procedural World Generation** - Worlds using Perlin noise or ore-made maps
- **Cellular Automata** - Dynamic world evolution and transformation
- **Pre-made Maps** - Support for custom map loading
- **Enemies & Food** - Interactive entities with AI behavior ❗ In Development ❗
- **Colorful Console** - Enhanced visual experience with rlutil
- **Extensive Configuration** - Highly modifiable game parameters
- **Object-Oriented Design** - Every symbol is a distinct game object

## Gameplay

### Controls
**Menu**
- **WS** or **Up Arrow, Down Arrow** - moving between options
- **Space, enter** - select
- **AD** or **Left Arrow, Right Arrrow** - additional switching within settings
- **Tab**

**Game**
- **WASD or Arrow Keys** - Move character
- **ESC** - Pause menu/Exit

### World System
Each character symbol represents a unique game object

Procedural terrain generation using FastNoiseLite

Cellular automata for organic world evolution

Support for both generated and pre-loaded maps

## Dependencies

**[rlutil](https://github.com/tapio/rlutil)** - simple utility collection to aid the creation of cross-platform console-mode roguelike games with C++ and C.

**[FastNoiseLite](https://github.com/Auburn/FastNoiseLite)** - an extremely portable open source noise generation library with a large selection of noise algorithms. This library focuses on high performance while avoiding platform/language specific features, allowing for easy ports to as many possible languages.
