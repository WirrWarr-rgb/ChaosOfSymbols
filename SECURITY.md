# Security Policy

## Policy

- **Cheats and mods are allowed** – do whatever you want with your copy.
- **Only report issues that harm users against their will or bugs in the regular version**

My policy is this: if a player wants to play a broken game, let them. You can do whatever you want with your version, as long as it doesn't interfere with others. I don't care about cheats, so enjoy!

## What's a Security Issue?

**Report these:**
- Game can damage files outside its folder
- Game steals personal data
- Crashes that corrupt system files

**Don't report these:**
- Any cheat or trainer
- Save file editing
- Memory editing (Cheat Engine)
- Game balance exploits
- Mods (unless they contain viruses)
